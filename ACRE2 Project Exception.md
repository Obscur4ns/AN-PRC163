## 1. Definitions

### 1.1 Copyright Holder

The **Copyright Holder** is the person or entity identified as the licensor in `LICENSE.md`.

### 1.2 Licensed Material

**Licensed Material** means original UKSF AN/PRC-163 material covered by `LICENSE.md`.

It does not include third-party material or any material that the Copyright Holder lacks authority to license.

### 1.3 ACRE2 Project Maintainer

An **ACRE2 Project Maintainer** is a person who, at the time the permission is exercised:

- holds write, maintain, or administrative access to the official `IDI-Systems/acre2` source-code repository; or
- holds equivalent authority in a successor repository formally designated by the ACRE2 project.

A person does not qualify merely because they:

- use ACRE2;
- contribute an issue or pull request;
- participate in an ACRE2 community;
- maintain an unofficial ACRE2 fork;
- describe themselves as an ACRE2 developer.

### 1.4 Official ACRE2 Fork

An **Official ACRE2 Fork** means a public source repository controlled by the ACRE2 project or by one or more qualifying ACRE2 Project Maintainers for the purpose of maintaining the UKSF AN/PRC-163.

6. publish compatibility, maintenance, security, and successor releases;
7. review, merge, revert, and transfer maintenance work between qualifying ACRE2 Project Maintainers;

This permission applies only while the person qualifies as an ACRE2 Project Maintainer, except that releases lawfully distributed while qualified remain authorised.

A modified release distributed under this exception must:

1. remain non-commercial;
2. be intended primarily for use with Arma and ACRE2;
3. retain the original copyright notice;
4. retain `LICENSE.md`, this exception, and applicable third-party notices;
5. clearly state that it is modified;
6. identify the maintainer or project responsible for the modified release;
7. include the preferred source form for the modified UKSF AN/PRC-163 material;
8. not imply endorsement by UKSF, UKSF Surplus, or the original authors;
9. not use UKSF branding in a way that could reasonably make an unofficial release appear official;
10. comply with all applicable third-party licences.

A modified release may use the original addon name only when its description clearly identifies the release as an ACRE2-maintained fork or modified version.

## 4. Licence of modified releases

Unless Section 5 applies, modified releases distributed under this exception must remain under:

- the APL-ND; and
- this ACRE2 Project Exception.

For the avoidance of doubt:

- qualifying ACRE2 Project Maintainers may distribute modified versions;
- members of the general public may redistribute an unmodified copy of an ACRE2-maintained release as permitted by the APL-ND;
- members of the general public may not distribute their own modified versions unless they receive separate permission or independently qualify under this exception.

This exception does **not** by itself permit the Licensed Material to be relicensed under the GNU General Public License or incorporated into ACRE2 as GPL-covered code.

Direct incorporation of original UKSF AN/PRC-163 code into the GPL-licensed ACRE2 project requires a separate written relicensing grant from the Copyright Holder.

This restriction does not affect:

- independently written ACRE2 code;
- pre-existing ACRE2 code;
- material already available under a GPL-compatible licence;
- mere runtime use of ACRE2 APIs or dependencies.

## 6. Contributions from other people

This exception does not automatically authorise a person who is not an ACRE2 Project Maintainer to distribute adapted UKSF AN/PRC-163 material.

Before accepting a public contribution containing adapted Licensed Material, the ACRE2 maintainers should ensure that the contributor:

- qualifies under this exception;
- is listed in `AUTHORISED_MAINTAINERS.md`; or
- has received separate written permission from the Copyright Holder.

Independent code that does not copy or adapt Licensed Material is outside this restriction, subject to its own licence.

## 8. Loss of maintainer status

A person who ceases to qualify as an ACRE2 Project Maintainer must not make new distributions under this exception unless separately authorised.

They may continue to:

- retain archival copies;
- use previously released versions as allowed by their licences;
- transfer project materials to a qualifying ACRE2 Project Maintainer.

Previously distributed releases and rights already granted to their recipients are not withdrawn solely because a maintainer later loses qualifying status.
