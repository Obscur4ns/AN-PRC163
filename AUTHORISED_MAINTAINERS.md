# Authorised Maintainers

Version 1.0 — 3 August 2026

This register identifies people who may distribute modified versions of original UKSF AN/PRC-163 material in addition to those automatically covered by the ACRE2 Project Exception.

## 1. ACRE2 Project Maintainers

Qualifying ACRE2 Project Maintainers are authorised automatically under:

`ACRE2_PROJECT_EXCEPTION.md`

They do not need to be individually named in this file while they meet the definition in that exception.

Their permission is limited by the terms and scope of that exception.

## 2. Additional named maintainers

No additional named maintainers are authorised by this register at version 1.0.

Add a person only with the copyright holder's approval.

Use the following record format:

```text
Name or stable account identifier:
Organisation or team:
Permission start date:
Permission end date, if any:
Authorised repositories:
Authorised material:
Permitted activities:
Permitted release channels:
May publish source: Yes/No
May publish compiled PBOs: Yes/No
May sublicense or transfer maintenance: Yes/No
Special conditions:
Approved by:
Approval date:
```

## 3. Scope of a named permission

Unless a person's entry expressly says otherwise, permission should be interpreted narrowly.

A named maintainer may not assume permission to:

- relicense the project;
- use the project commercially;
- use it outside Arma;
- transfer permission to another person;
- grant access to restricted third-party assets;
- represent an unofficial release as an official UKSF release.

## 4. Contributors are not automatically maintainers

Submitting:

- bug reports;
- test results;
- code suggestions;
- pull requests;
- documentation;
- translations;
- assets;

does not automatically grant maintenance or distribution rights.

Contribution terms and copyright ownership should be agreed before accepting substantial contributions.

## 5. Removal or expiry

When a named permission expires or is withdrawn:

- the person must stop making new modified distributions;
- releases lawfully made while authorised remain subject to their accompanying licences;
- project source and credentials should be transferred or removed as directed by the copyright holder;
- third-party confidential or restricted material must not be retained beyond any applicable permission.
